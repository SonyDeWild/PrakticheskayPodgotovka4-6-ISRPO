# Отчёт о тестировании LibraryApp

## 1. Объект тестирования

Консольное приложение LibraryApp на C# (.NET 8) для учёта книг в библиотеке.
Приложение позволяет добавлять книги, искать их по Id, выдавать и принимать обратно.
Классы: `Book` (книга), `Library` (список книг и операции), `Program` (точка входа).

## 2. Методика тестирования

- Ручное тестирование: запуск приложения и проверка сценариев в консоли.
- Отладка в Visual Studio: точки останова в методах `BorrowBook`, `ReturnBook`, `FindBook`,
  пошаговое выполнение (F10, F11), окна Locals и Watch.
- Статический анализ кода: анализаторы компилятора, окно Error List,
  проверка стандартов именования и XML-документации.

 ## 3. Найденные дефекты

D-01. Выдача несуществующей книги вызывает исключение.
Шаги воспроизведения: вызвать BorrowBook(99).
Ожидаемый результат: сообщение «книга не найдена».
Фактический результат: возникает NullReferenceException, программа аварийно завершается.
Статус: исправлен.

D-02. Повторная выдача уже выданной книги.
Шаги воспроизведения: дважды вызвать BorrowBook(2).
Ожидаемый результат: отказ при повторной выдаче.
Фактический результат: книга выдаётся второй раз, сообщения об ошибке нет.
Статус: исправлен.

D-03. Возврат книги, которая не была выдана.
Шаги воспроизведения: вызвать ReturnBook(3) для книги, которая не выдавалась.
Ожидаемый результат: сообщение, что книга не была выдана.
Фактический результат: выводится «Книга возвращена», состояние книги меняется некорректно.
Статус: исправлен.

D-04. Возврат несуществующей книги.
Шаги воспроизведения: вызвать ReturnBook(99).
Ожидаемый результат: сообщение «книга не найдена».
Фактический результат: возникает NullReferenceException.
Статус: исправлен.

## 4. Результаты инспекции кода

При статическом анализе в окне «Список ошибок» были выявлены следующие замечания, и все они исправлены:

CS1591: отсутствует XML-документация у публичных классов и методов. Исправление: добавлены XML-комментарии <summary>, <param> и <returns> для классов и методов.
IDE0044: поле books можно сделать доступным только для чтения. Исправление: добавлен модификатор readonly.
Дублирование проверки на null в методах BorrowBook и ReturnBook. Исправление: проверка вынесена в приватный метод GetBookOrReport.
Отсутствие проверки аргумента в методе AddBook. Исправление: добавлено исключение ArgumentNullException.
Лишние директивы using. Исправление: неиспользуемые директивы удалены.

## 5. Итоги

После исправлений все три сценария (несуществующая книга, повторная выдача,
возврат невыданной книги) обрабатываются корректно, приложение не падает.
Предупреждений анализатора не осталось. Автоматические тесты не использовались,
проверка выполнялась вручную и в отладчике.

Рекомендации: добавить модульные тесты (xUnit) для методов `Library`,
использовать `bool` или исключения вместо вывода в консоль внутри бизнес-логики,
добавить хранение данных в файле или БД.
