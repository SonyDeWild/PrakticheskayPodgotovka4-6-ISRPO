# LibraryApp

Консольное приложение на C# (.NET 8) для учёта книг в библиотеке.
Умеет добавлять книги, искать по Id, выдавать и возвращать их.

## Запуск

1. Установите Visual Studio 2022 с рабочей нагрузкой «.NET desktop development» и .NET 8 SDK.
2. Клонируйте репозиторий: `git clone <ссылка на репозиторий>`
3. Откройте файл `LibraryApp.sln` в Visual Studio.
4. Нажмите F5 (или Ctrl+F5) для запуска.

## Структура

- `Book.cs`: класс книги
- `Library.cs`: логика библиотеки
- `Program.cs`: точка входа
- `TEST_REPORT.md`: отчёт о тестировании
